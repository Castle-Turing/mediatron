# The engine may still be too much browser

qutebrowser is the chosen engine ([m1-constraints]): the vim grammar
and window come free. The recorded fallback if its remaining chrome,
weight, or startup proves wrong for a reading surface: a custom
minimal shell (a webview widget, a keymap, nothing else). This entry
exists so that fallback is a considered alternative with a home, not
a rewrite argued from frustration in some future session. Evidence
that would activate it: the-window-is-cold's measurements, or house
styling needs qutebrowser cannot express.
