# docs/state — what is true now

Documents here are current truth: maintained, authoritative, patched
in the same PR that changes what is true. Everything else under
`docs/` is record. The full rules — clause keys, `[stated]` versus
`[inferred]`, four-field constraints, deletion review, the
extraction rule — live in `AGENTS.md`'s "Truth and records" section,
which is the one canonical statement; this README is a pointer for
strangers, not a second copy.

The public/private line, drawn explicitly: state documents carry
this project's own direction — mechanism any deployment inherits.
Nothing about the resident's life, taste, or priorities appears
here; the resident's palette and preferences override the house
defaults from their private configuration and are never committed.
